# 项目自动认领间隔 UI 设计

## 目标

优化项目自动认领设置中的自定义分钟数布局，使标签、输入框和单位在同一行清晰地两端对齐；移除与执行中心重复的上一轮执行结果提示。

## 真实操作路径

`ProjectAutomationMenu` 的“间隔”入口 → 选择“自定义”并输入整数分钟 → `submitChange` 调用上层 `onChange` 写入 `intervalMinutes` → 设置面板重新读取并展示保存值。

## 方案

- 将自定义分钟数容器改为与其他设置相同的 `project-automation-field` 单行布局。
- 左侧展示“自定义分钟数”，右侧使用水平控件组放置数字输入框和“分钟”单位，控件组整体右对齐。
- 保留现有整数校验、`1～1440` 范围校验、失焦/Enter 保存和错误提示行为。
- 删除仅由 `lastIssue` / `lastOutcome` 生成的上一轮执行结果提示。
- 保留联网限制说明和不可用原因提示，因为它们反映当前设置的必要状态。

## 范围与接口

- 仅修改 `web/src/components/ProjectAutomationMenu.tsx` 和 `web/src/styles.css`。
- 不修改后端接口、数据结构或自动认领逻辑。

## 验收标准

1. 自定义分钟数标签位于行左侧，输入框与“分钟”位于行右侧且同一基线。
2. 切换预设、自定义输入、失焦或 Enter 保存行为保持不变。
3. 非法输入仍显示现有错误提示且不会提交。
4. 设置面板不再显示上一轮执行结果，但联网限制和不可用原因仍可显示。
